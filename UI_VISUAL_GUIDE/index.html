    CRISP-T Web UI - Visual Overview¶

    Configuration Panel (Left)¶

    The left panel contains:

    1. Model Selection Dropdown
    2. Dynamically populated with all available models from GitHub Copilot SDK
    3. Includes GPT-5.2, GPT-5.1, GPT-5, GPT-4.1, GPT-4o, and more
    4. Claude models: Opus 4.6, Opus 4, Sonnet 4.5, Sonnet 4, Sonnet 3.5, Haiku 3.5
    5. OpenAI o-series: o3-mini, o1-preview, o1-mini
    6. Models are loaded from the API or fallback to comprehensive list

    7. Available models depend on your GitHub Copilot subscription

    8. Data Source Input

    9. Text field for path to data files

    10. Example: ./data or /path/to/research

    11. Advanced Settings (Collapsible)

    12. Custom Provider checkbox
    13. Provider configuration (when checked):
      • Provider Type (OpenAI/Azure/Anthropic)
      • Base URL
      • API Key

    14. GitHub Token (optional)

    15. Control Buttons

    16. Start Session (primary button)

    17. Stop Session (appears when active)

    18. Status Indicator

    19. Green dot + "Connected (model)" when active
    20. Gray dot + "Not connected" when inactive

    Chat Panel (Right)¶

    The right panel contains:

    1. Header
    2. Title: "Chat with CRISP-T"

    3. Subtitle: "Ask questions about your qualitative research data"

    4. Messages Area (Scrollable)

    5. Welcome message with examples
    6. User messages (right-aligned, blue)
    7. Assistant messages (left-aligned, gray)
    8. Typing indicator (animated dots)

    9. System messages (centered, info style)

    10. Input Area

    11. Multi-line text box for composing messages
    12. Send button
    13. Keyboard shortcut: Enter to send, Shift+Enter for new line

    Color Scheme¶

    • Primary Blue: #0366d6 (buttons, links, user messages)
    • Background: #f6f8fa (light gray)
    • Panel Background: #ffffff (white)
    • Text: #24292e (dark gray)
    • Borders: #e1e4e8 (light gray)
    • Success: #28a745 (green - for connected status)
    • Error: #d73a49 (red - for errors)

    Responsive Design¶

    The interface adapts to different screen sizes:

    • Desktop (>1024px): Two-column layout as shown above
    • Tablet (768-1024px): Config panel above chat panel
    • Mobile (<768px): Stacked layout, optimized for small screens

    Interactive Elements¶

    1. Start Session Button
    2. Hover: Darker blue
    3. Disabled: Gray

    4. Shows "Starting..." during initialization

    5. Chat Messages

    6. Fade-in animation when new messages appear
    7. Auto-scroll to bottom on new messages

    8. Code blocks with syntax highlighting

    9. Typing Indicator

    10. Three animated dots
    11. Appears while AI is thinking

    12. Removes when response arrives

    13. Configuration

    14. Real-time validation
    15. Clear error messages
    16. Tooltips for help

    Accessibility¶

    • Semantic HTML structure
    • ARIA labels for screen readers
    • Keyboard navigation support
    • High contrast mode compatible
    • Focus indicators on interactive elements

    Browser Compatibility¶

    Tested and working on: - Chrome 90+ - Firefox 88+ - Safari 14+ - Edge 90+

    Performance¶

    • Lightweight: ~50KB total (HTML + CSS + JS)
    • Message polling: 500ms intervals
    • Auto-cleanup of inactive sessions
    • Efficient DOM updates

    For more details, see the full documentation in docs/ui.md
